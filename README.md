# dfir-writeups
Blue-team investigation write-ups: HackTheBox Sherlocks and CyberDefenders labs

Full investigation reports from HackTheBox Sherlocks and CyberDefenders blue-team labs, written as incident reports rather than CTF walkthroughs: executive summary, attacker timeline, IOC tables, ATT&CK mapping, and remediation recommendations. Cases cover Windows forensics, network traffic analysis, memory forensics, and email compromise. All write-ups are for retired or publicly available challenges in line with each platform's publication policy.

Status: In progress — first investigations underway.
